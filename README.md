# El Marché

An AI-powered marketplace that brings Algeria's online sellers into one searchable platform — helping buyers find what they want at the right price, and helping sellers grow beyond social media.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (PostgreSQL, Auth, Storage)
- Vercel (deployment)

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000 in your browser.
